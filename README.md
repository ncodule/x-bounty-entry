# X post entry: make your own bounty

![rank](https://make.fun/badge/post-x-promote-make-your-own-bounty-01/dikikurniawan23/x-bounty-entry/rank.svg)

This repository hands in one public post on X for the
[make.fun bounty page](https://make.fun/bounty/post-x-promote-make-your-own-bounty-01).
The post quotes the announcement that anyone can now sponsor a bounty of
their own, and POST.json in this folder holds the post address.
Running main.ts copies that file to the output folder unchanged.
